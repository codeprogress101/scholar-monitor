## Classification rules

| Classification | Meaning in this report |
|---|---|
| Fully Implemented | Inspected code supports the answer's stated software scope, with related existing tests/evidence. Does not certify human compliance, live configuration, official authority or operational activation. |
| Partially Implemented | A relevant supported path exists, but a specific workflow/default/evidence piece is absent or incomplete. |
