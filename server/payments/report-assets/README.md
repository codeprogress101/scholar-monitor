# Reconciliation PDF fonts

Unmodified Noto Sans Regular and Bold, distributed under the included SIL Open
Font License. Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
(downloaded 23 October 2026). These are embedded/subset by PDFKit so Filipino
names, accents and combining characters do not depend on host Windows fonts.

The build copies these exact assets and license beside the compiled renderer.
The generator performs no network fetch or system-font discovery. No official
municipal logo, certification, accounting number or signatory is introduced.
